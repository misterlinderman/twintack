# Claude Notes Reference

## Overview

The `claude notes` directory at the root level of the project contains reference files and conversation exports from interactions with Claude, Anthropic's AI assistant. These notes serve as valuable resources for guiding feature expansions and layout modifications throughout the TwinTack project.

## Purpose

The Claude notes directory serves several important purposes:

1. **Feature Planning**: Documents discussions about planned features and their implementation details
2. **Design Decisions**: Records rationales behind design and layout choices
3. **Problem Solving**: Archives solutions to technical challenges encountered during development
4. **Knowledge Continuity**: Ensures insights and decisions are preserved for future reference
5. **Implementation Guidance**: Provides detailed instructions for implementing complex features

## Directory Structure

The `claude notes` directory is organized as follows:

- **Feature-specific notes**: Files related to specific features or components
- **Design discussions**: Notes about UI/UX decisions and layout considerations
- **Technical solutions**: Documentation of solutions to technical challenges
- **Future enhancements**: Ideas and plans for future development

## Using Claude Notes

When working on the TwinTack project, consider the following best practices for using the Claude notes:

1. **Before implementing new features**: Check the Claude notes directory for relevant discussions and guidance
2. **When modifying existing features**: Review notes related to the feature to understand the original design intent
3. **When encountering challenges**: Look for similar issues that may have been addressed in previous conversations
4. **After significant conversations**: Export and add new notes to maintain a comprehensive record

## Contributing to Claude Notes

To maintain the usefulness of this resource:

1. **Name files descriptively**: Use clear, specific names that indicate the content
2. **Include dates**: Add creation dates to file names or within the content
3. **Organize by topic**: Group related notes together
4. **Summarize key points**: Include brief summaries at the beginning of each file
5. **Cross-reference**: Link to related notes or code files when relevant

## Integration with Documentation

The Claude notes complement the formal documentation by providing:

- More detailed context behind implementation decisions
- Exploratory discussions that led to specific features
- Alternative approaches that were considered
- Specific code examples and implementation guidance

When updating the formal documentation (such as FEATURES.md), reference relevant Claude notes for additional context.
